EXPERIMENTAL RESEARCH STUDY

Optimizing Digital Rendering Speed vs. Hardware Resource Usage in CSS Technical Workstations

DATE: Q3 2026

1. Problem Statement

As a Grade 12 Computer Systems Servicing (CSS) student and digital illustrator, high-resolution canvas rendering can throttle hardware resources on standard workstations. This study tests how layer optimization and vector caching affect rendering latency.

2. Experimental Methodology

Conducted benchmarks on 4K digital canvases comparing standard raster layer stacks against GPU-accelerated vector smart objects across different memory configurations (8GB vs 16GB RAM setups).

3. Key Findings

Rasterizing heavy adjustment filters into smart memory caches reduced GPU render latency by 38.4% and freed up RAM overhead during complex multi-layer poster composition export.

4. Practical Application

Implemented these technical findings directly into my illustration design pipeline, enabling faster brush strokes, smoother pan/zoom response, and zero-lag 300 DPI print poster exports.
